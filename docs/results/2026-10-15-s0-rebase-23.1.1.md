Traps met:

- A `rack sh` that timed out at 60 s left the remote shallow `git fetch`
  running, and its `shallow.lock` and `index.lock` blocked the next git
  command. Give the fetch minutes.
- A copy of the stack's sysroot carries libc++ 22's headers. Under the
  libc++ 23 install one of them made `<vector>` fail (`cctype` `#error`
  about `<ctype.h>`). `runtimes.sh` now deletes the old C++ runtime files
  from the copy first.
- `/usr/bin/cargo` runs the rustup `rustc` that comes first on `PATH`
  unless it is given `RUSTC=/usr/bin/rustc`.
- `rustc` called directly needs `-Zunstable-options` for a JSON target in
  1.99.0.
- busybox `date` on the card has no `%N`; timings use `/proc/uptime`.
